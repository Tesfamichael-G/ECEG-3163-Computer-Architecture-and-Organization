## Free online resources 🆓

- **Logisim** — [cburch.com/logisim/](http://www.cburch.com/logisim/) — educational digital circuit simulator, used for the CPU project.
- **MARS** — [courses.missouristate.edu/KenVollmar/MARS/](http://courses.missouristate.edu/KenVollmar/MARS/) — MIPS simulator.
- **Ripes** — [github.com/mortbopet/Ripes](https://github.com/mortbopet/Ripes) — visual RISC-V simulator with pipeline view.
- **Nand2Tetris** — [nand2tetris.org](https://www.nand2tetris.org/) — build a computer from NAND gates up; excellent complement to this course.
- **Berkeley CS61C** — [cs61c.org](https://cs61c.org/) — great course materials on computer architecture.
- **MIT 6.004** — [ocw.mit.edu/courses/6-004-computation-structures-spring-2017/](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/) — computation structures.
- **Onur Mutlu's lectures** — [youtube.com/@OnurMutluLectures](https://www.youtube.com/@OnurMutluLectures) — excellent video lectures on memory systems.
- **Hennessy & Patterson online appendices** — [elsevier.com/books](https://www.elsevier.com/books) — free supplementary material for the textbook.

## Recommended first-week reading

- **Stallings §1.1–§1.3** — organization vs architecture, the Von Neumann model.
- **Mano §1.1–§1.2** — basic computer organization.
- **Nand2Tetris project 1** — start building basic logic gates (excellent hands-on complement).
