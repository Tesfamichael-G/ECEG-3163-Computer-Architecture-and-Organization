## What you will learn

<div class="grid cards" markdown>

- :material-chip: **Understand computer organization and architecture**

    ---

    The distinction between organization and architecture, the Von Neumann model, the evolution of computing (Moore's law, generations), and the basic components of a computer system.

- :material-calculator: **Master computer arithmetic**

    ---

    Signed number representations, integer addition/subtraction/multiplication/division, IEEE-754 floating-point representation, and floating-point arithmetic.

- :material-code-braces: **Analyse instruction sets and CPU structure**

    ---

    Instruction formats (R, I, J), addressing modes, register transfer notation, CPU register organization, and the RISC vs CISC debate.

- :material-pipe: **Design pipelines and control units**

    ---

    Pipelining stages, hazards (structural, data, control), forwarding, branch prediction, and the design of hardwired vs microprogrammed control units.

- :material-memory: **Design memory systems**

    ---

    Cache organization (direct-mapped, set-associative, fully associative), replacement policies, write policies, AMAT analysis, virtual memory, TLB, and disk technologies.

- :material-usb: **Design I/O systems**

    ---

    Programmed I/O, interrupt-driven I/O, DMA, bus architectures, and disk I/O performance.

- :material-lan-connect: **Explore advanced topics**

    ---

    Parallel processing models (SISD/SIMD/MISD/MIMD), multicore, GPU computing, low-level data structures, and an introduction to operating systems.

</div>
